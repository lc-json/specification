# LC-JSON reference Python tools — runtime dependencies
#
# Supported Python: 3.11+ (the version the spec repo's CI runs). Earlier 3.x
# may work but is not tested; failures on < 3.11 are unsupported-environment,
# not tool defects.
#
# validate_course.py uses jsonschema for primary schema validation. The three
# new-type validators (lc_collection.py, lc_pack.py, lc_glossary.py) run a shared
# Draft-07 schema front-stage (_lcjson_schema.py) that also uses jsonschema when
# it is installed; if jsonschema is absent they degrade to domain checks only and
# say so. run_corpus.py and assemble_pack_bundle.py add no dependencies of their
# own. All tools run on the standard library alone; jsonschema is the single
# optional dependency that enables full schema validation.
#
# Install:
#     pip install -r tools/requirements.txt
#
# Or, outside a virtualenv:
#     pip install --user -r tools/requirements.txt
